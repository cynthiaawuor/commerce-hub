## 1. Project Overview

The Merchandise Management System (MMS) is a distributed backend suite designed to digitally mirror the physical flow of goods and money through a retail business. It eliminates manual data entry, scattered spreadsheets, and siloed knowledge by providing automated, real-time visibility into procurement, inventory, warehouse operations, and financial accounting.

## Prerequisites

- Node.js (v18+)
- npm

## 1. Initialize the Project

Create the folder for your service and initialize a blank Node.js project.

```bash
mkdir service-vendor
cd service-vendor
npm init -y
```
